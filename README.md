<summary>TᕼIᑎGS ᗯOᖇTᕼ ᗰEᑎTIOᑎIᑎG</summary>
I started this project back in 2018. The thing was that at the time I did not speak English and my art sucked, so it was never posted before. I had still written things for this story which is why the comic is a bit “old-school”. I started this around the time Cuphead and Bendy were at the peak of their popularity fandom-wise. People often made crossovers for those two fandoms, this is why Bendy *is* in this story. Of course, as I've restarted working on it in 2026, you may see some elements from The Cuphead Show I lasted watched in 2023 that may accidentally appear from memory as I write and draw the comic. This project is still being worked on and things might change or be erased as I progress on it. Each part of the comic will sadly be coming slowly because I'm the only artist / person working on it.
</details>
